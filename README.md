# 해법독서논술 (고양파주지사) 공식 홈페이지

천재교육 해법독서논술 고양파주지사 맞춤형 반응형 공식 웹사이트입니다.

## 📌 주요 구성 및 기능
- **지사소개**: 20년 경력의 문해력 전문가 지사장 인사말 및 교육철학
- **커리큘럼**: 4단계 독서토론논술 학습 프로세스
- **교재분석**: 예비초(키움), 초등(바움/생각짱글짱/넓은나무), 중등(로스트럼), 역사특강 심층 분석
- **입시정보**: 2028 대입 개편안 완벽 분석 및 고교학점제, 서·논술형 평가 전략, 고양·파주 지역 학군 칼럼
- **우리동네 교실찾기**: 고양시(일산동구, 일산서구, 덕양구) 및 파주시(운정, 금촌, 문산) 교실 검색
- **1:1 빠른 상담신청**: 학부모 학습상담 & 예비원장님 가맹/창업 상담 폼

## 🛠️ 기술 스택
- HTML5, CSS3, Vanilla JavaScript (ES6+)
- Tailwind CSS
- FontAwesome Icons
- Pretendard Font
